## 一、品类聚焦：精品配饰 + 美妆辅助工具

### 1.1 为什么这两个品类适合当前策略

| 维度 | 精品配饰 | 美妆辅助工具 |
|------|---------|-------------|
| 重量 | 极轻（<50g）✅ | 轻量（<200g）✅ |
| 毛利 | 60-80% ✅ | 50-70% ✅ |
| 视觉冲击 | 佩戴效果对比强烈 ✅ | before/after天然种草 ✅ |
| AI视频适配 | 数字人佩戴展示 | 使用过程演示 |
| SKU深度 | 款式多、测品快 | 功能差异化明显 |
| 物流成本 | 极低 | 低 |
| 侵权风险 | 中（避免大牌仿款） | 低-中 |
| 复购 | 中（收集属性） | 高（消耗+升级） |

### 1.2 具体SKU方向

**精品配饰:**
- 耳饰（耳钉/耳环/耳线）— 视觉最好、单价低、起量快
- 项链/锁骨链 — 叠戴趋势
- 手链/手镯 — 套装组合拉客单价
- 发饰（抓夹/发箍/丝带）— 美妆联动
- 戒指 —  adjustable款降低尺码问题

**美妆辅助工具:**
- 美妆蛋/粉扑 — 高频消耗品
- 睫毛夹/睫毛刷 — before/after效果明显
- 修眉刀/眉笔 — 教程类视频友好
- 洗脸仪/导入仪小件 — 客单价较高
- 收纳包/化妆包 — 配饰联动
- 美甲工具/贴片 — TikTok热门

### 1.3 定价策略

```

物流成本：￥3-8（小包）
平台佣金：5-8%

─────────────
售价区间：$3-15（东南亚）/ $5-20（俄罗斯）
```

## 三、AI视频多语言验证（Phase 1 核心）

### 3.1 验证目标

**核心假设需要验证：**
1. AI数字人视频能否在东南亚市场获得有效互动（完播率>30%、CTR>2%）
2. 多语言本地化（泰/越/印尼/马来/俄）是否能达到本地化效果
3. 同一产品不同语言视频，哪个市场ROI最优
4. AI视频 vs 真人实拍的成本效率比

### 3.2 实验设计

**对照组设置：**

| 实验组 | 内容类型 | 语言 | 数量 | 目的 |
|--------|---------|------|------|------|
| A | AI数字人口播 | 泰语 | 10条/SKU | 验证AI+泰语 |
| B | AI数字人口播 | 英语 | 10条/SKU | 基准对照组 |
| C | 产品混剪(无口播) | 无/BGM | 10条/SKU | 验证纯视觉 |
| D | AI配音+产品实拍素材 | 泰语 | 5条/SKU | 混合方案对照 |

**每SKU至少跑50条视频、7天数据**

**核心指标：**
- 完播率 (Watch-through rate)
- 点击率 (CTR)
- 转化率 (CVR)
- 单视频出单成本
- 评论情感（是否识别出AI感）

### 3.3 AI视频制作流水线（精益版）

```
Step 1: 脚本
  输入：产品图片+卖点+目标语言
  工具：Claude/GPT → 多语言脚本
  产出：30s口播脚本 × 5种语言

Step 2: 数字人视频
  工具选择（按成本排序）：
  - Kling AI (快手) — 成本最低，中文生态好
  - HeyGen — 多语言质量最高，$24/月起
  - D-ID — 照片驱动，适合产品讲解
  - 自部署SadTalker/MuseTalk — 长期成本最低

  推荐起步：Kling AI + HeyGen 双轨测试

Step 3: 配音
  - Fish Audio — 东南亚语言质量好，免费额度
  - ElevenLabs — 英语/俄语顶级
  - 平台内置TTS — 最低成本

Step 4: 后期
  - CapCut (剪映海外版) — 自动字幕+特效
  - 模板化：片头3s钩子 → 产品展示 → 使用效果 → CTA

Step 5: 去重变体
  - 换BGM / 换片头 / 换封面 / 换CTA话术
  - 1个原始视频 → 5-10个变体
```

### 3.4 多语言本地化要点

| 市场 | 文化注意 | 视频风格偏好 | 数字人选择 |
|------|---------|-------------|-----------|
| 泰国 | 佛教元素、色彩明亮 | 可爱/甜美风 | 泰裔面孔 |
| 越南 | 年轻化、韩流影响 | 时尚/精致 | 东亚面孔 |
| 菲律宾 | 英语+他加禄混用 | 热情/直白 | 混血/东南亚面孔 |
| 马来/印尼 | 穆斯林着装得体 | 温和/家庭感 | 戴头巾女性可加分 |
| 俄罗斯 | 审美要求高 | 精致/专业感 | 东欧面孔 |

## 七、Agent开发优先级（配合2人团队）

### 立即可做（Week 1-2）：

1. **Listing Agent** — 用Claude/GPT批量生成多语言标题+描述
   - 输入：1688链接/产品图 → 输出：5语言listing文案
   - 实现：Prompt模板 + API调用脚本
   - 节省：80%上架时间

2. **客服自动回复** — 基于平台消息+LLM
   - 实现：定时拉取消息 → LLM生成回复 → 人工审核后发送
   - 初期人工审核，逐步自动化
   - 覆盖：80%常见问题

### 第二批（Week 3-6）：

3. **选品数据Agent** — 定时爬取趋势数据
4. **视频效果追踪** — 汇总各视频数据，自动标注top/bottom

### 第三批（Month 2-3）：

5. **广告优化Agent** — 自动调整出价/预算分配
6. **库存预警** — 基于销售速度预测补货时间
